# reklama.vesnins.com

Медиакит канала «Мистер Полумарафон». Статическая страница без сборки.

```
index.html   вся страница: разметка, стили и скрипт в одном файле
img/         hero.webp, run.webp, portrait.webp, og.jpg
```

## Деплой

Сайт развёрнут через Coolify на сервере 103.88.243.96.

- Build Pack: **Static**
- Base Directory: `/`
- Domain: `https://reklama.vesnins.com`

Сборки нет — файлы уже готовые. Любой push в `main` можно
задеплоить кнопкой Deploy в панели Coolify. Если включить
**Is Git Polling** в настройках ресурса, Coolify будет сам
проверять репозиторий раз в несколько минут и выкатывать изменения.

## Как обновлять содержимое

Всё правится в `index.html` — можно прямо на GitHub через
веб-редактор (карандаш в интерфейсе), можно локально.

Что меняется чаще всего:

| Что | Где искать в файле |
|---|---|
| Подписчики в верхней строке | блок `<div class="ticker">` |
| Подписчики в карточках площадок | блок `<section id="channels">` |
| Возрастная диаграмма | `data-w` — длина полосы в процентах от максимума |
| Пол, гео | блок с классом `split` в секции `#audience` |
| Цены | `<section id="price">` |
| Тематики | `<div class="tags">` |

После правки цифр в диаграмме не забудь пересчитать `data-w`:
это доля от самой большой группы, а не от ста процентов.
Сейчас максимум — 44,1 % у группы 35–44, поэтому у неё `data-w="100"`.

## Картинки

Обрезаны из исходных снимков. При замене сохраняй пропорции,
иначе поедет вёрстка:

| Файл | Пропорции | Где |
|---|---|---|
| `hero.webp` | 3:4 | первый экран |
| `run.webp` | 2:1 | полоса с цитатой |
| `portrait.webp` | 4:5 | блок контактов |
| `og.jpg` | 1200×630 | превью при отправке ссылки |

## Шрифты

Unbounded (заголовки), Onest (текст), JetBrains Mono (цифры) —
подключены с Google Fonts. Все три поддерживают кириллицу.
